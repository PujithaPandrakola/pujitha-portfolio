# Pujitha Portfolio

Interactive portfolio website built using React.js, Tailwind CSS, Framer Motion, and Vite.

## Live Website

https://pujitha-portfolio-psi.vercel.app/

## Features

- Animated Hero Section
- Orbiting Skills Animation
- Interactive Skills Showcase
- 3D Project Cards
- GitHub Stats Integration
- AI Assistant
- Voice Introduction
- Dark/Light Theme Toggle
- Responsive Design
- Smooth Scroll Navigation

## Tech Stack

- React.js
- Tailwind CSS
- Framer Motion
- JavaScript
- Vite

## Projects Included

- Telecom Churn Prediction
- Book Recommendation System
