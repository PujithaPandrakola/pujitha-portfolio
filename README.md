# Pujitha Portfolio

Interactive portfolio website built using React.js, Tailwind CSS, and Framer Motion.

## Features

- Animated Hero Section
- Orbiting Skills Animation
- Interactive Projects Showcase
- GitHub Stats
- AI Assistant
- Voice Introduction
- Dark/Light Theme
- Responsive Design

## Tech Stack

- React.js
- Tailwind CSS
- Framer Motion
- JavaScript
- Vite
